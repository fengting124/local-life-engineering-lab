## 本地测试入口

### Java Server

```bash
mvn -pl local-life-server test
mvn -pl local-life-server clean verify
mvn -pl local-life-server test-compile org.pitest:pitest-maven:mutationCoverage
```

本轮已执行完整 `clean verify`：`183` 条单元测试与 `5` 条 Failsafe 集成测试通过，JaCoCo 门禁通过。PIT 生成 `136` 个变异体，杀死 `87` 个；该数字用于当前分支的回归证据，不与不同 PIT 配置的历史结果直接比较。

### Java MCP Server

```bash
mvn -B -pl local-life-copilot clean verify
```

本轮结果为 `134 tests, BUILD SUCCESS in 53.63s`。MySQL 8.4 Testcontainers 从空库应用全部迁移，并验证 HITL 跨语言签名、审批 CAS、租约恢复和并发消费合同。

### Python Agent Service

```bash
cd copilot-agent-service
DEBUG=false PYTHONPATH=. .venv/bin/python -m pytest -q tests
```

本轮已执行，结果为 `655 passed, 1 warning in 9.93s`。Mutation 门禁结果为 `826/1180 killed`、`other=0`、kill rate `70.0%`，未降低阈值。

### 跨进程 Smoke

```bash
export HITL_PAYLOAD_SIGNING_SECRET='<从 Secret Manager 或本地安全输入注入>'
python3 scripts/hitl-security-smoke.py
```

本轮执行了 HITL 专项跨进程 smoke，五个 Lite 容器均健康，`copilot:V104` 已应用，7 个场景全部通过。脚本使用隔离数据并在结束后清理；不会删除现有 Docker volume。

## 已知限制

- 本文不把历史测试数字作为当前事实；任何新提交都会使本轮数字变成历史证据。
- 本轮没有重新测 Agent 模型质量、Token 成本、后端容量或长稳性能，相关结论继续引用性能基线报告。
- `7/7` 是固定 HITL 安全场景通过数，不代表所有故障组合已穷举，也不代表全局分布式 exactly-once。
- 面试表达中的测试数字应同时说明命令、代码基线、日期和边界，不只背一个通过数。
