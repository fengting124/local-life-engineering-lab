# 环境搭建

- Status: Active
- Type: How-to
- Owners: Project maintainers
- Last verified: 2026-07-12
- Source of truth: `pom.xml`, `copilot-agent-service/requirements.txt`, `infra/docker-compose.dev.yml`, `README.md`

本文给出 LocalLife 本地开发的可复制环境基线。它不记录个人机器路径、个人用户名或一次性环境快照。

## 适用读者

- 第一次运行本仓库的开发者。
- 需要核对 JDK、Maven、Python、Docker 版本的维护者。

## 当前状态

当前项目使用 Java 17、Maven、多模块 Spring Boot、Python Agent Service 和 Docker Compose 管理的基础设施。

## 最低版本

| 工具 | 最低或推荐版本 | 证据 |
| --- | --- | --- |
| JDK | 17 | `pom.xml` 的 `java.version` |
| Maven | 3.9.x | 根 `pom.xml` 和 CI Maven 命令 |
| Python | 3.11 推荐 | `.github/workflows/copilot-agent-service-ci.yml` |
| Docker | 支持 Compose v2 | `infra/docker-compose.dev.yml` |
| MySQL | 8.4 | `infra/docker-compose.dev.yml` |
| Redis | 7.4-alpine | `infra/docker-compose.dev.yml` |

## 通用环境变量

使用变量示例，不写个人绝对路径：

```bash
export PROJECT_ROOT="${HOME}/projects/local-life-engineering-lab"
export JAVA_HOME="${JAVA_HOME:-/path/to/jdk-17}"
export MAVEN_HOME="${MAVEN_HOME:-/path/to/apache-maven-3.9.x}"
export DATA_DIR="${DATA_DIR:-${PROJECT_ROOT}/data}"
```

Windows PowerShell 示例：

```powershell
$env:PROJECT_ROOT = "${HOME}\projects\local-life-engineering-lab"
$env:JAVA_HOME = "${JAVA_HOME}"
$env:MAVEN_HOME = "${MAVEN_HOME}"
```

## 验证命令

在仓库根目录执行：

```bash
java -version
mvn -v
python --version
docker -v
docker compose version
```

预期结果：

- `java -version` 显示 Java 17。
- `mvn -v` 使用 Java 17。
- `docker compose version` 能正常输出 Compose 版本。

## 启动基础设施

本地基础设施以 `infra/docker-compose.dev.yml` 为准：

```bash
docker compose -f infra/docker-compose.dev.yml up -d mysql redis
bash infra/scripts/init-db.sh
```

`infra/scripts/init-db.sh` 在宿主机执行时会优先使用本机 `mysql` CLI；如果没有安装，会自动复用正在运行的 `local-life-mysql` 容器内客户端。手工排查时可用：

```bash
docker exec local-life-mysql mysqladmin ping -h localhost -uroot -p123456
docker exec local-life-mysql mysql -uroot -p123456 -e "SELECT 1;"
```

验证 MySQL 和 Redis：

```bash
docker compose -f infra/docker-compose.dev.yml ps mysql redis
docker exec local-life-mysql mysql -uroot -p123456 -e "SELECT 1;"
docker exec local-life-redis redis-cli ping
```

MySQL 和 Redis 使用 `restart: unless-stopped` 并通过 named volume 持久化数据。
Docker Desktop 或 daemon 意外重启后，它们会自动恢复；如果显式执行
`docker compose stop mysql redis`，Docker 会保留这个人工停止意图，不会自行拉起。
恢复后用上述 `ps` 命令确认两者均为 `healthy`，无需删除数据卷。

## 启动应用服务

常用顺序：

```bash
mvn -pl local-life-server spring-boot:run
mvn -pl local-life-copilot spring-boot:run
cd copilot-agent-service
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Docker Compose 应用栈入口以 [项目 README](../../README.md) 为准。

## 已知限制

- Java CI 使用 MySQL 和 Redis service；本地完整 `verify` 也需要 Docker 可用。
- Agent Service 的 RAG 和模型能力依赖 `.env` 和模型服务配置；无模型 key 时只能运行不依赖真实模型的测试。
- 历史个人机器状态、磁盘迁移和一次性阻塞记录不再放入 Active 环境文档。
