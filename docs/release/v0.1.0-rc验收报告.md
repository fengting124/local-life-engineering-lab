# v0.1.0-rc 验收报告

- Status: Active
- Type: Reference
- Owners: Project maintainers
- Last verified: 2026-07-15
- Source of truth: `scripts/demo-smoke.sh`, `scripts/business-simulate.sh`, `scripts/e2e-smoke.sh`, `scripts/run-rag-benchmark.sh`, `.github/workflows/*.yml`

本文记录 `LocalLife Engineering Lab` 的 `v0.1.0-rc` 验收口径。它不是生产发布声明，而是用于面试演示、回归验证和后续正式发布前的证据入口。

## 适用读者

- 准备面试演示的项目维护者。
- 需要确认本地 Docker 全栈是否可跑通的开发者。
- 需要排查 Server、MCP、Agent、RAG、日志栈是否联通的 reviewer。

## 当前状态

当前 `main` 已合入 `release(agent): consolidate runtime hardening stack`：

- PR: `#16`
- Merge commit: `5fa66dace6828e2159d9b9e3e3ec37d7d33dba7d`
- CI 结果：`docs`、`test`、`verify`、`mutation`、`test-and-mutation` 全部通过。

`v0.1.0-rc` 的目标是补齐一条可复制的本地验收路径：

1. 拉起或复用 Docker 全栈。
2. 写入 deterministic demo 业务数据。
3. 验证 Java Server、Java MCP Server、Python Agent 的跨服务链路。
4. 验证 Agent runtime event replay 能作为排障入口。
5. 运行 RAG benchmark，至少保留 offline 质量口径；真实 Milvus/Reranker 口径按环境启用。
6. 产出本次运行证据到 `artifacts/demo-smoke/<timestamp>/`。

## 验收命令

如果服务已经启动：

```bash
bash scripts/demo-smoke.sh
```

如果需要脚本先启动服务：

```bash
START_STACK=1 bash scripts/demo-smoke.sh
```

如果需要重新构建镜像：

```bash
START_STACK=1 SKIP_BUILD=0 bash scripts/demo-smoke.sh
```

如果需要跑真实 RAG benchmark：

```bash
INCLUDE_RAG_REAL=1 bash scripts/demo-smoke.sh
```

## 已知限制

- `demo-smoke.sh` 默认验证 deterministic Fast Path，不默认触发真实 LLM ReAct/HITL 审批，以避免演示稳定性依赖外部模型和人工操作。
- 真实 RAG benchmark 需要 Milvus、embedding-service、reranker-service 都已启动；默认只跑 offline benchmark。
- 日志栈入口是可选检查。Grafana、Loki、Alertmanager 未启动时脚本记录 `WARN`，不阻断核心业务验收。
- 本报告是 RC 验收入口，不代表已经完成短时 bearer token、LangGraph 官方 `interrupt()/Command(resume=...)`、长期记忆治理和生产级指标面板。
